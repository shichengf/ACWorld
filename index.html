01 / Abstract

Commerce needs more than a final answer.

ACWorld makes every accepted market effect attributable, reconstructable, and independently scorable.

In vibe commerce, people express buying or selling goals in natural language and delegate the work to agents. Unlike a single assistant using a fixed website, commerce requires independently controlled Buyers and Merchants to interact while preserving private objectives and distinct authority.

ACWorld separates an agent's decision from the authority to change shared state. The Vibe Commerce Protocol (VCP) binds proposed actions to their actors, the Commerce Intelligence Platform validates them, and the World commits only authorized effects.

The resulting trace connects each decision to validation, execution evidence, and state change. Evaluators can replay and rescore a transaction without rerunning the model.

02 / Architecture

Decision, validation, and effect stay separate.

No model response has commercial effect until it passes the same typed, auditable path.

01 · INTENT

Role-specific agent

A Buyer or Merchant pursues a private natural-language mandate with its own skills and visible state.

→
02 · MESSAGE

Vibe Commerce Protocol

Every proposed action carries actor identity, typed content, and the context needed for authorization.

→
03 · CHECK

Platform validation

The Commerce Intelligence Platform checks market rules and current state, then rejects or authorizes.

→
04 · EFFECT

Deterministic World

Accepted events update shared inventory, orders, payments, trust, and evidence through replayable commits.

CHECK / 01Authenticated actor

Every action belongs to one identified Buyer or Merchant.

CHECK / 02No direct mutation

Messages never update the shared World by themselves.

CHECK / 03Authorized commit

Each state change cites an accepted platform validation.

CHECK / 04Exact replay

Ordered commits reproduce the final state and event digest.
