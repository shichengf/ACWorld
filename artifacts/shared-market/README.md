# ACWorld shared-market study records

These files describe the paper's single 5-by-5 market with GPT-5.6 Terra and seed 42. They contain the structured Merchant quotes, Buyer choices, allocation, settlement evidence, and study report. The study demonstrates bilateral decisions, shared allocation, and settlement in a persistent World.

The three JSON files are unchanged copies of the archived experiment records. SHA256SUMS binds this package. Cite arXiv:2608.02441v1.
